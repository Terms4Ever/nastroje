## 📁 Struktura projektu

```
aplikace/
├── src/          # obrazovky a logika
├── assets/       # obrázky a ikony
└── app.json      # nastavení Expo
```

Každá vypsaná cesta musí existovat.

---

## 🚀 Instalace (lokální vývoj)

```bash
git clone https://github.com/Terms4Ever/nazev.git
cd nazev
npm install
npx expo start
```
